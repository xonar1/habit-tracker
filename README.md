# Habit Tracker — Git-лаборатория

Учебный проект для отслеживания привычек и отработки основных возможностей Git и GitHub.

## О проекте

Habit Tracker предназначен для изучения команд Git, работы с ветками, объединения изменений и разрешения конфликтов. В проекте также используется Python и автоматическое тестирование с помощью pytest.

## Возможности

- Подсчёт текущей серии выполнения привычки (streak).
- Работа с историей коммитов.
- Создание и переключение между ветками.
- Объединение веток с помощью merge.
- Изучение rebase и разрешение конфликтов.
- Автоматический запуск тестов через GitHub Actions.

## Технологии

- Python 3.11
- Git
- GitHub Actions
- pytest

## Запуск тестов

Установите pytest:

```bash
pip install pytest
```

Запустите тесты из корневой папки проекта:

```bash
pytest -v
```

## Основные команды Git

```bash
git status
git add .
git commit -m "описание изменений"
git log --oneline --graph --all
git branch
git switch -c feature/my-feature
git merge feature/my-feature
```

## GitHub Actions

При отправке изменений в репозиторий GitHub Actions запускает настроенный процесс автоматической проверки проекта. Бейдж в начале README показывает статус последнего соответствующего запуска workflow `ci-cd.yml`.

- **Зелёный бейдж** — проверка прошла успешно.
- **Красный бейдж** — проверка завершилась ошибкой.
- **Серый бейдж** — запуск ещё не выполнен или статус недоступен.

## Цель проекта

Закрепить навыки работы с Git, научиться вести историю изменений и использовать автоматическое тестирование при разработке программного обеспечения.
